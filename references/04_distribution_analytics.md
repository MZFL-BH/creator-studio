# 04 发布分发与数据复盘指南

## 一、 核心发布平台差异化文案规范

| 平台 | 标题风格 | 封面与正文侧重点 | 核心流量密码 |
| :--- | :--- | :--- | :--- |
| **小红书** | 口语化 + 情绪痛点 + 关键词（带表情符号） | 封面大字报突出痛点；正文必须分段并带序号，附带 3~5 个精准热门标签 | 搜素权重极高，正文多埋关键词 |
| **B站 (Bilibili)** | 深度好物/硬核拆解/故事悬念型长标题 | 封面突出人物反差表情或核心视觉冲击点；置顶评论引导长篇讨论 | 完播率与弹幕密度（互动率） |
| **视频号 / 抖音** | 结论前置 + 黄金 3 秒强冲突反差短标题 | 竖版满屏视觉；前 2 秒必须出现核心动作或大字幕提问 | 完播率与即时转发率 |

## 二、 完播率与漏斗健康度诊断表

| 诊断指标 | 危险阈值 | 核心问题归因 | 针对性优化动作 |
| :--- | :--- | :--- | :--- |
| **前 2 秒跳出率** | > 40% | 开头拖泥带水，视觉信息过弱，封面与开头内容不符 | 砍掉片头一切打招呼废话，开头即扔结论或反问 |
| **5 秒完播率** | < 25% | 核心吸引点交代太慢，节奏拖沓 | 加快前段剪辑节奏，每 2~3 秒切换一次景别或文字动效 |
| **平均停留时长** | < 视频总长 30% | 中段内容注水，说教感太重，缺少情绪起伏 | 中段增加真实翻车案例或反常识对比作为二段钩子 |
| **互动点赞比** | < 3% | 纯娱乐看完即走，缺少“利他”收藏价值或吐槽共鸣点 | 结尾必须明确指引单一互动动作（如“扣 1 领资料”、“你怎么看在评论区聊聊”） |
