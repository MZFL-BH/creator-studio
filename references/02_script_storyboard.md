# 02 脚本与分镜抗压参考指南

## 一、 黄金 3 秒（Hook）五大开场范式
1. **下结论/亮态度**：开门见山直接扔结论，不作铺垫（“千万别再用 XX 了，纯属交智商税”）。
2. **反向提问/戳痛点**：“你是不是也经常剪视频剪到凌晨，播放量却不过百？”
3. **视觉/动作前置**：视频开头 1 秒立刻出现特写、突发动作或反常画面，绝不用静止半身中景开头。
4. **悬念留白**：“如果我告诉你，这个方法能帮你每天省下 2 小时，你敢信吗？”
5. **数字量化**：“从 0 到 10 万播放，我只做对了这 3 件事”。

## 二、 短视频标准四列分镜模板

拍摄前必须将台词转化为具有执行力的四列表格：

| 时间戳 | 景别与画面动作 | 台词 / 口播文案 | 音效与情绪引导 |
| :--- | :--- | :--- | :--- |
| **00:00 - 00:03** | 【特写】手机屏幕快速划走画面，镜头快速推近主角挑眉 | “别划走！如果你也在做自媒体，这段可能救你的命。” | 【音效】急促划屏嗖声 + 警报音<br>【情绪】紧张、好奇 |
| **00:03 - 00:15** | 【中景】主角坐下，指向身后的白板（白板写核心痛点） | “大多数人完播率低，不是你讲得不好，而是开头废话太多。” | 【音效】转场顿音<br>【BGM】轻快节奏鼓点淡入 |
| **00:15 - 00:45** | 【特写切客体】展示电脑端自动化剪辑工具运作界面 | “今天教你用一个脚本，直接切掉所有气口，省下一半时间。” | 【音效】鼠标点击清脆声 |
| **00:45 - 01:00** | 【全景/中景】主角直视镜头总结，做出互动手势 | “具体脚本已打包，评论区扣 666，带走直接跑。” | 【BGM】高潮上扬收尾 |
